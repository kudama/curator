# Decisions and sources

Curator's feature list comes from the “Media server features” chat and the Curator section of the Jarvis vision supplied on September 30, 2026. The feature-list preview included library hygiene, storage forecasting, smart transcoding, playback diagnosis, metadata, home movies, backups, upgrades, and an operations dashboard.

The README summarizes that direction. Record types, endpoints, acceptance criteria, and detailed job behavior are new theoretical proposals, not previously implemented software. No current media inventory, filesystem paths, viewing history, or live capacity measurements are copied here.

Begin with a read-only inventory and findings prototype. Agree on preservation/quality rules before any write-capable worker. Integrate Curator with Jarvis through bounded observations and separately authorized actions.
