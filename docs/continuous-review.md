# Continuous review

**Ready for review** is an inbox across libraries for completed videos. Filter by
library, type or search, then choose **Start reviewing** for the matching upscale
and encoding results. Multipart joins remain available through their separate
boundary-review action.

Each comparison opens automatically. **Accept & publish** queues the verified
installation and advances; **Reject result** resets the task and advances;
**Skip / Next** leaves it pending for another session. Keyboard shortcuts are
**A**, **R** and **S**. They do not run while typing, while a decision is saving,
or when the corresponding action is disabled. Publication still finishes and
verifies in Queue; acceptance does not claim it is already published.

The session's item versions, decisions and position live in Curator's database.
The browser remembers only its session identifier. **Resume review** reconciles
changed or missing jobs with their actual state and continues without replaying
any publication. Skipped items remain in the inbox and can enter a new session.
Each session contains at most 5,000 results; additional results stay available
for the next session.
