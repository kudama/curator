The application uses Python's standard library and ships its own HTML, CSS, and JavaScript. External executables, model weights, artwork, fonts, and media are not bundled.

Plex API conventions were checked against the PlexAPI project documentation, including its metadata edit and media selection interfaces. Curator uses an independent HTTP adapter rather than importing PlexAPI. Reference: https://github.com/pkkid/python-plexapi .

Optional integrations are separately installed and retain their own terms and licenses: Plex Media Server, FFmpeg/ffprobe, HandBrakeCLI, Topaz Video, Ollama and selected model weights, Mage, and Kometa.
